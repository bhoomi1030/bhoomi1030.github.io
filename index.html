QuickStay: Hotel Booking

A full-stack hotel booking platform where users search hotels, view rooms and make reservations.

Backend design
  • Layered Node.js / Express REST API: routes, controllers, middleware and Mongoose models.
  • MongoDB schemas for users, hotels, rooms and bookings, linked by references, with booking status and payment status enums.
  • Date-range overlap query that checks room availability before a booking is created, to prevent double-booking.
  • Booking price computed from nights stayed and nightly rate.
Security & integrations
  • Clerk authentication middleware protects the API routes.
  • Signature-verified webhook syncs user create, update and delete events to the database.
  • Stripe payments and a responsive React.js frontend.
